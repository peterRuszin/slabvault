# SlabVault

A portfolio tracker for sports cards and collectibles.
Track your collection, monitor market value, and analyse your returns.

## Stack
- Java 21
- Spring Boot 3.4
- PostgreSQL
- Maven

## Getting Started
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your values
3. Run `docker-compose up -d` to start the database
4. Run `mvn spring-boot:run`
